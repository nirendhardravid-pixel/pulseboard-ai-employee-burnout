# PulseBoard AI – Employee Burnout Prediction

## 📌 Project Overview
PulseBoard AI is a Machine Learning project designed to predict
employee burnout risk using workplace and employee-related factors.

The project uses machine learning algorithms to identify employees
who may be at risk of burnout and provides insights into the
factors influencing burnout.

## 🎯 Objectives
- Predict employee burnout risk using Machine Learning.
- Identify important factors contributing to burnout.
- Explain model predictions using SHAP.
- Build an interactive application using Streamlit.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- XGBoost
- SHAP
- Streamlit
- Matplotlib
- Seaborn

## ⚙️ Key Features
- Employee burnout risk prediction.
- Machine Learning model comparison.
- Explainable AI using SHAP.
- Interactive dashboard using Streamlit.

## 📊 Machine Learning Models
- Random Forest
- XGBoost
